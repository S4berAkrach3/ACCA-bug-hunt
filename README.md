# Bug hunt

Five small bugs are hidden in this project. Your job is to find out what's wrong with each one and fix it, the way a developer would: by reading the error, searching, and asking AI.

## How it works

1. Your bugs are in the **Issues** tab. Do them **in order**, starting with Bug 1.
2. Each issue tells you what's going wrong, but not how to fix it. Working that out is the point.
3. Fix each bug on its own branch, named exactly `fix-bug-1`, `fix-bug-2` and so on.
4. Open a pull request. The **Check the fix** check tests your fix. Merge only when it has a green tick.
5. If the check fails, click **Details** to read the error. Fix it on the same branch, and the check runs again.

## Rules

- Try to solve it yourself first: read the error, search, ask AI. That's the skill you're practising.
- Fill in every part of the pull request description, including what you searched for.
- Only open the hint in each issue after you've genuinely tried.
